test_5kb.txt -- a 4,962-byte file copied into every demo image.

hello.txt is only 12 bytes: it fits in a single cluster, and reading it
never follows a FAT chain.  This file exists to show the opposite case.
It is deliberately larger than one cluster, so reading it forces the
library to hop from cluster to cluster through the FAT:

  FAT12 demo image (720 KB floppy, 1024 B/cluster): 5 clusters,
  chain 3 -> 4 -> 5 -> 6 -> 7.

  FAT16 demo image (16 MiB, 512 B/cluster): 10 clusters.
  FAT32 demo image (33 MiB, 512 B/cluster): 10 clusters.

The tests pin this file at exactly 4,962 bytes -- the cluster chains and
sizes they assert depend on it -- so the rest is numbered filler with the
byte offset of each line, letting you watch a multi-cluster read sweep
through the file in order.
